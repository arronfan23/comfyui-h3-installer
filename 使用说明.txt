====================================================
  ComfyUI + H3 模型  在线一键安装
  三猫云 SanMaoCloud 出品
====================================================

【配置要求】
  - Windows 10 / 11 64 位
  - NVIDIA 显卡（RTX 20 系或更新），显存建议 16GB 以上
  - 最新显卡驱动
  - 磁盘剩余空间：75GB 以上
  - 全程联网，共下载约 70GB（模型 64GB + PyTorch 等 5GB）
    模型支持断点续传，中断后重跑会自动接着下

【安装方法】
  双击「一键安装.bat」，等待完成即可。
  - 全程自动：下载并安装 Python 3.12、ComfyUI 主程序、
    PyTorch (cu130)、H3 全套模型、Node.js，并配置 Codex MCP
  - 默认装到「本文件夹旁边的 ComfyUI 目录」
  - 完成后自动启动 ComfyUI 并打开 http://127.0.0.1:8188
  - 视网速约 1~3 小时，看到"安装完成"即成功
  - 国内网络无需手动设置：HuggingFace 连不上会自动切换
    ModelScope 国内高速源（魔搭，Comfy-Org 官方镜像，速度快）

【日常使用】
  1. 双击 ComfyUI 文件夹里的「启动ComfyUI.bat」
  2. 打开 Codex，直接用自然语言让它画图 / 生成视频
     （安装时已自动配置好 comfyui MCP，重启 Codex 后生效）

【常见问题】
  - 杀毒软件拦截 PowerShell：选择允许；全部脚本开源可查看
  - 中途中断：重新双击「一键安装.bat」，已完成步骤自动跳过，
    模型下载自动断点续传
  - 国内用户强制走国内源下载模型：
      powershell -ExecutionPolicy Bypass -File installer\install.ps1 -UseMirror
  - 自定义安装目录：
      powershell -ExecutionPolicy Bypass -File installer\install.ps1 -InstallDir "E:\AI\ComfyUI"

【模型来源】
  全部模型安装时从 HuggingFace 官方仓库下载（未转存）：
  - Comfy-Org/MiniMax-H3   （H3 主模型 / 32B 文本编码器 / VAE）
  - Comfy-Org/Qwen3-VL     （4B fp8 文本编码器）
